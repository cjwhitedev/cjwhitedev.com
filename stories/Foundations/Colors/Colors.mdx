# Colors

Several brand colors make up the palette. Themes map them to roles, so components
use `--bg`, `--fg`, `--primary` and `--secondary` rather than palette names.

## Themes

- `white`: default, for page sections.
- `light`: alternate with `white` to separate sections.
- `dark`: header and footer. Stays the same in dark mode.
- `dark-sec`: occasional contrast on light pages. Replaces `white` in dark mode.
- `dark-ter`: replaces `light` in dark mode.

Layout and Navbar also accept `inherit`, which adds no theme and uses the
surrounding one. Header and Footer set their own theme and pass `inherit` down
to their Layout and Navbar. Card defaults to `contrast`, which
picks the dark theme furthest from its parent: `dark-sec` on `white` and `light`,
`dark` on `dark-sec` and `dark-ter`, and `dark-ter` on `dark`.

## Accessibility

Every theme is measured below. Body text must reach 7:1 and links 4.5:1. The
`--secondary` color is for non-text accents only and is not held to a text
ratio. The story fails if a theme drops below those minimums, and every
component story is also checked by axe in each theme.

## Dark mode

When the visitor prefers a dark color scheme, `white` becomes `dark-sec` and
`light` becomes `dark-ter`. Themes that are already dark do not change, and
neither do themes set by hand, so a header stays `dark`. The Storybook theme
toggle applies the same swap through an `engine--mode-dark` class on the page,
and `engine--mode-light` forces light regardless of the system setting. The
panels below are the same ones as above, rendered in dark mode.
